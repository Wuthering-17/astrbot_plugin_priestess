## 功能

### 账号与签到

- 森空岛扫码绑定、游戏角色刷新、默认角色切换和 `-r 序号` 临时角色选择；目前一个 QQ 对应一个森空岛账号。
- 明日方舟与终末地于北京时间 **00:15 同批自动签到**，覆盖账号中对应游戏的角色；启动、更新或重载后的当天补签静默执行，失败每 5 分钟重试。
- 自动签到结果只发往本人选择的绑定群，只展示在该群绑定或设置通知的成员；私聊绑定不自动发送群通知。
- 自动签到失败、校时阻塞与任务异常可私聊安装者配置的 QQ，按日期、接收人和失败项目去重；默认不设置接收人。
- 插件内部网络校时，调度和森空岛请求签名使用校准时间，不修改操作系统时间；首次校时失败时等待重试。
- 账号体检、缺失默认角色修复；定期体检仅报告，手动清理前保存备份。

### 终末地

- 开盒展示全部干员的技能等级与专精、武器、四件装备、套装和战术道具；支持 `@群友`。
- 抽卡查询与每日同步、复刻池处理、免费与赠送抽区分、小黑盒早期记录导入和撤销。
- 群内欧非榜、指定卡池全群对比和逐抽明细；多页个人记录和卡池对比在 QQ 使用合并转发。
- AKEData 干员、武器、套装与散件资料，支持昵称、同音与模糊检索；数据下载失败可重试并复用已下载文件。
- 群友配装与高难通关配队统计、战争回响与影拓丰碑目录、完整攻略图片、竞速榜与出场率。
- 战绩和配装采集同时处理 5 名成员，每完成 50 人保存一次；请求间保留间隔，榜单随采集逐步更新。单接口失败保留该接口的旧记录。

### 明日方舟

- 角色卡（可 `@群友`）、抽卡记录、集成战略战绩、公开招募计算与理智查询。
- 小黑盒导出文件导入，校验绑定 UID、去重；群内欧非榜与指定卡池对比。

### 通知与群功能

- 两款游戏活动日历与活动开启图片，展示开始、结束、总持续及剩余时间；可分别指定发送群，夜间开启的活动早上统一通知。
- 群周报：群精华、任务、竞速、轮换、活动与卡池；默认不 `@全体`，可配置发送群。
- 理智回满订阅提醒、90% 理智／体力预警、资料库更新通知。
- 所有主动提醒均有总开关及分类开关；关闭提醒不会关闭后台签到、更新或手动查询。
- OneBot 入群邀请处理；动态订阅和关键词词库未迁移。

## 架构

```text
QQ ↔ NapCat / OneBot v11 ↔ AstrBot 4.28.2
                              └─ astrbot_plugin_priestess/main.py
                                  ├─ 森空岛账号、API、SQLite
                                  ├─ 资料库、攻略、榜单、日历、提醒
                                  └─ AstrBot 图片服务 / Playwright 无头浏览器
```

直接作为 AstrBot 插件运行，无需部署第二个 NoneBot 服务。

## 安装与更新

1. 在 AstrBot 插件页通过仓库地址安装：`https://github.com/Wuthering-17/astrbot_plugin_priestess`；或从 [Releases](https://github.com/Wuthering-17/astrbot_plugin_priestess/releases) 下载 ZIP 后上传安装。
2. 等待依赖安装与插件加载；在插件配置中选择需要的提醒和目标群。
3. 发送 `/skl绑定`，使用本人森空岛 App 扫码，随后发送 `/森空岛签到` 验证。
4. 若图片提示缺少浏览器，在 **AstrBot 所用 Python 环境**运行：

   ```bash
   python -m playwright install chromium
   ```

Linux 还需系统浏览器依赖和中文字体，可按 Playwright 安装说明执行 `python -m playwright install --with-deps chromium`。

更新前先停止机器人并备份 `data/plugin_data/astrbot_plugin_priestess/`。更新后检查版本号，必要时重启 AstrBot。
插件数据保存在插件目录之外，更新代码不应删除绑定数据。

旧版本目录名 `astrbot-plugin-priestess` 会尝试整体迁移到下划线名称；Windows 热更新时目录被占用则暂用旧目录，重启后再试。
若新旧目录均有数据，插件会停止迁移以避免覆盖；请停机备份并人工核对，不要直接合并两个 SQLite 文件。

## 配置

主要配置在 AstrBot 的插件配置页保存，完整定义见 [_conf_schema.json](_conf_schema.json)。
管理员命令使用 **AstrBot 管理员 ID**，QQ群管理员身份不会自动获得权限。

### 活动群与失败私聊

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `activity_arknights_groups` | 空 | 方舟活动开启通知群，多个群号用逗号分隔 |
| `activity_endfield_groups` | 空 | 终末地活动开启通知群，独立于方舟 |
| `sign_failure_notify_qq` | 空 | 自动签到失败私聊接收 QQ，可填多个；机器人需能向其私聊 |

留空即不发送相应消息。活动首次初始化不补发已开启活动；关闭提醒或未设置群期间发生的活动不在之后补发。
部分目标群发送失败时只重试失败群，不重复发给已成功的群。

### 主动提醒开关

以下布尔项均默认开启；总开关与对应分类开关同时开启才会主动发送。

| 配置项 | 控制内容 |
| --- | --- |
| `notify_all` | 所有主动提醒的总开关 |
| `notify_wiki_update` | AKEData 数据更新群通知 |
| `notify_activity_arknights` / `notify_activity_endfield` | 两款游戏各自的活动开启图片 |
| `notify_weekly_report` | 定时群周报 |
| `notify_sanity_arknights` / `notify_sanity_endfield` | 回满群提醒，仍需本人 `/理智提醒 开` 订阅 |
| `notify_stamina_arknights` / `notify_stamina_endfield` | 90% 预警，发往账号最近保存的消息来源 |
| `notify_daily_sign_group` | 自动签到绑定群汇总 |
| `notify_sign_failure_private` | 账号或游戏签到失败私聊 |
| `notify_clock_failure_private` | 初次校时失败、暂缓签到的私聊 |
| `notify_sign_job_failure_private` | 签到任务异常中断私聊 |
| `notify_health_private` | 定期体检结果私聊 AstrBot 管理员 |

三类签到私聊共用 `sign_failure_notify_qq`；体检使用 AstrBot 管理员列表。
关闭开关不影响后台工作、手动预览、绑定结果或 `/全群签到` 的直接回复。

### 签到通知与群周报

- 群内绑定会保存绑定群；私聊绑定不设置群。旧账号可由本人在目标群发送 `/签到通知 本群`，无需重新绑定。
- `/签到通知 关闭` 仅关闭本人的自动签到群通知，后台签到继续。
- 周报群列表位于数据目录下的 `weekly_report/config.json`。文件不存在时默认面向所有已加入群；例如 `{"groups":[123456789]}` 限定群，`{"groups":[]}` 不发送。默认不 `@全体`。
- 资料库更新通知仍采用其原有群发送范围，可用 `notify_wiki_update` 关闭；活动群列表不控制这类通知。
- `skland_github_proxy_url`、`skland_github_token` 为既有保留字段，当前尚未接入插件配置读取，不能依靠填写它们解决下载问题。

多页个人抽卡和群卡池对比使用合并转发。记录覆盖期可能不同，排名仅供参考。

## 定时任务

均为北京时间。签到使用内部校准时间，其余任务仍使用操作系统时间；机器人需保持运行。

| 时间／周期 | 任务 | 发送规则 |
| --- | --- | --- |
| 启动、更新或重载后 | 当天静默补签；启动各后台任务 | 不发补签群汇总；配置后的失败私聊仍可发送 |
| 每天 00:15 | 双游戏签到，失败每 5 分钟重试 | 每天一次绑定群简洁汇总，尊重开关 |
| 每天 01:00 | 终末地抽卡记录同步 | 后台更新 |
| 每天 03:00 | 群友配装采集 | 后台更新 |
| 每天 05:30、17:30 | 高难战绩、配队与榜单采集 | 5 名成员并发，每 50 人保存；配装数据缺失或规则过期时补采配装 |
| 启动约 30 秒后 | 初次高难数据采集 | 同上；不会额外群发采集结果 |
| 每 10 分钟 | AKEData 版本检查、理智回满检查 | 各自通知开关与订阅规则 |
| 每小时 | 90% 理智／体力预警检查 | 最近消息来源与对应开关 |
| 每 5 分钟 | 活动开启检查 | 两款游戏各自指定群；00:00—08:00 开启的活动延至早上 |
| 每 30 分钟 | 方舟活动数据刷新（PRTS 有独立缓存周期） | 后台更新 |
| 每天 06:00 | 检查机器人所在群的管理员身份 | 后台更新 |
| 每周日 19:00 | 群周报 | 周报配置群，默认不 @全体 |
| 每周一 04:00 | 账号体检 | 仅报告给管理员，不自动删除 |

采集耗时取决于账号数量、接口限流与网络；不会承诺固定半小时完成。任务期间可查询已经保存的部分结果。

## 数据与隐私

- 数据目录：`data/plugin_data/astrbot_plugin_priestess/`，包括 `skland.db`、抽卡记录、统计快照、通知状态、缓存和备份；不要公开上传整个数据目录。
- 森空岛凭据用于绑定账号的游戏查询和签到；请只绑定本人账号，不在聊天日志、Issue 或截图中公开凭据。
- 群友开盒、榜单、配队与周报会展示部分绑定数据。可通过对应游戏欧非榜／攻略统计命令退出，签到群通知另行控制。
- 小黑盒导入核对游戏 UID；导入的早期记录与官方记录进行去重，不将其他玩家的记录记到本人名下。
- 浏览器使用临时无头会话，不加载个人浏览器登录配置。
- 内部校时只访问已有森空岛／鹰角 HTTPS 服务时间，不携带账号凭据，也不改 Windows 时间。系统校时工具未随插件分发。
- 原版 NoneBot 数据库与本插件模型不同，不能直接复制使用；旧 AstrBot 数据目录迁移不等于 NoneBot 数据迁移。

## 常见问题

### 自动签到没有执行或通知

检查机器人是否在线、插件是否成功加载。日志搜索“网络校时成功”、`每日`、`签到`。
启动补签不会发群汇总；老账号先在目标群发 `/签到通知 本群`，并开启 `notify_all` 与 `notify_daily_sign_group`。
私聊绑定不会自动通知任何群。初次校时失败会暂缓签到；凭据或接口失效仍需处理，无法保证所有失败均自动恢复。

### 为什么角色资料失败、图标缺失或图片超时

先由管理员执行 `/资料库更新`，检查 AKEData 和图片站连通性。HTTP 500 属于资料服务异常，可稍后重试；已成功下载的文件会复用。
确认无头浏览器与中文字体已安装。渲染超时会重试一次，仍失败则回复“生成图片超时”；原始资料无图时不能凭空补图。

### 为什么配装或配队查不到

管理员执行 `/攻略数据更新` 可同时更新；也可分别执行配装／配队更新。角色须为成员默认终末地角色，且本人未退出统计。
配装有样本门槛，配队需要实际高难最佳记录；只有四个主页展示位不限制全干员开盒，但资料源缺字段时仍可能显示不全。

### 为什么竞速榜或抽卡是文字／多条消息

无参数选关菜单及出场率仍可为文字；具体竞速结果为图片。多页抽卡在 NapCat 使用合并转发，失败时可能回退逐页发送。
对比只用已保存记录，先更新个人抽卡再比较；当前没有“一键刷新全群两款游戏抽卡”的通用命令。

### 管理命令没有权限

在 AstrBot 管理员 ID 列表配置 QQ，重载或重启后再试。还应检查插件是否启用、命令前缀及其他插件是否拦截消息。
