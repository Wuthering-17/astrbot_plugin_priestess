# Priestess Bot

将 Priestess-bot 的明日方舟、明日方舟：终末地功能接入现有 AstrBot QQ 机器人。

北京时间 00:15 同批签到方舟与终末地，完成后向有已绑定成员的 QQ 群各发送一次简洁汇总。更新、重载或启动时的当天补签静默执行，不发群消息；失败每 5 分钟重试，重试不重复群通知。`/全群签到` 仍正常回复简洁汇总。

竞速榜图片：`/回响竞速` 查看本周关卡，`/竞速榜 关卡名` 查看单关，`/丰碑竞速 丰碑名` 查看系列。单关展示前 20 名，多关每关前 5 名，并额外保留自己的排名；无参数的选关菜单仍是文字。

## 安装与使用

运行环境：**AstrBot 4.28.2+、Python 3.12+、NapCat / OneBot v11**。

1. 在 AstrBot 的「插件」页面点击「＋」，上传发布 ZIP；也可以使用本仓库地址安装。
2. 等待依赖安装并确认插件加载成功。
3. 发送 `/skl绑定`，使用森空岛 App 扫码绑定。
4. 发送 `/森空岛签到`，同时签到明日方舟和终末地。

| 指令 | 作用 |
| --- | --- |
| `/skl帮助` | 查看指令帮助 |
| `/skl绑定` 或 `/sk login` | 扫码绑定森空岛 |
| `/森空岛签到` 或 `/sk sign` | 两款游戏一起签到 |
| `/全群签到` 或 `/群签到` | AstrBot 管理员为当前 QQ 群所有已绑定成员签到两款游戏，一条消息按“方舟状态 / 终末地状态 / 群昵称”逐人展示并汇总；✅ 已签到、❌ 失败、⚠️ 部分失败或异常、— 无角色 |
| `/明日方舟签到` | 仅签到明日方舟 |
| `/终末地签到` | 仅签到终末地 |
| `/skl角色更新` | 更新绑定账号的游戏角色 |
| `/zmd导入小黑盒 小黑盒ID` | 补回小黑盒中的早期终末地抽卡记录 |
| `/方舟导入小黑盒 导出链接 [-r 角色序号]` | 导入明日方舟小黑盒记录，按 UID 校验并去重 |
| `/zmd撤销小黑盒导入` | 撤销小黑盒导入记录 |
| `/方舟欧非榜 [常规/限定/中坚]` | 比较本群默认方舟角色的平均六星抽数，各类至少 2 个六星参与 |
| `/方舟欧非榜 退出` 或 `加入` | 控制是否参与方舟榜，独立于终末地榜单设置 |
| `/卡池对比 卡池名或ID [明细]` | 展示本群默认角色的指定卡池统计、排名及六星明细；追加“明细”展示全部逐抽记录 |
| `/方舟卡池对比 卡池名或ID` | 指定明日方舟卡池 |
| `/终末地卡池对比 卡池名或ID` | 指定终末地卡池 |
| `/配装数据更新` 或 `/skl配装数据更新` | AstrBot 管理员手动更新配装，独立于高难战绩接口 |
| `/配队数据更新` 或 `/群友配队更新` | AstrBot 管理员单独采集高难通关配队，两个接口独立更新，失败保留旧记录 |
| `/配队 角色名` 或 `/群友配队 角色名` | 图片查看本群成员的通关配队，1 人即可展示，注明采集时间 |
| `/zmd开盒` 或 `/终末地卡片` | 全干员练度表，展示技能等级与专精、武器、装备和套装；不局限于森空岛四个展示位 |
| `/攻略数据更新` 或 `/skl攻略数据更新` | AstrBot 管理员更新高难战绩及配装，返回分项采集结果 |

每日自动签到时间为中国时间 **00:15（明日方舟与终末地同批执行）**。
明日方舟导入使用小黑盒抽卡分析页底部「数据管理」生成的 HTTPS 文件下载链接，
不是小黑盒 ID。成功后发送 `/明日方舟抽卡记录` 查看；重复导入不会增加重复记录。
明日方舟榜单按平均六星抽数升序比较，越少越欧；去掉每池末尾未出六星的垫抽。
先在群里让参与者绑定森空岛并查询 `/明日方舟抽卡记录`，或导入小黑盒历史，再发送 `/方舟欧非榜`。
只统计机器人已保存的记录，覆盖期不同，排名仅供参考；`/欧非榜` 仍为终末地榜。

QQ/NapCat 的多页个人抽卡记录使用合并转发，每页一条节点；单页仍直接发图。
卡池对比读取当前群成员各自默认角色的已保存记录，不自动刷新游戏接口。
同名多期卡池会提示 ID，不混算；已退出对应游戏欧非榜的用户不参与展示。
所有有该池记录的参与者都会展示，至少 2 个有效六星才排名；免费抽单列，不计入平均抽数。
多页群友卡池对比也使用合并转发；完整逐抽记录请追加 `明细`。
资料库遇到 HTTP 500 等临时错误会重试，并保留同一版本已下载的文件供下次继续。
数据和凭据存放在 `data/plugin_data/astrbot_plugin_priestess/`，不随仓库发布。

小黑盒读取和本地图片渲染需要后台浏览器。默认使用 Playwright 自带的无界面 Chromium；
Windows 未安装该内核时尝试已安装的 Edge、Chrome。每次创建临时浏览器会话，
不加载个人浏览器配置或登录状态。其他环境可在 AstrBot 使用的 Python 中运行
`python -m playwright install chromium` 安装内核。

## 适配范围与验证

当前包含森空岛绑定、双游戏签到、角色和抽卡查询、理智提醒、终末地资料库和攻略、
日历、群内欧非榜、小黑盒导入与撤销、群周报、账号体检等接口。

当前一个 QQ 仅支持绑定一个森空岛账号；上游的多账号管理、关键词词库等功能仍有适配差异，
完整列表见 [ASTRBOT_PORT.md](ASTRBOT_PORT.md)。

v0.1.4 已在 Windows 的 Python 3.12 环境结合 AstrBot 4.28.2 源码验证压缩包识别、
完整入口导入、插件对象创建、空数据库初始化及后台 Edge 临时会话启动。
真实森空岛签到、小黑盒账号数据读取及所有 QQ 群功能尚未完成端到端验证。

修复记录见 [CHANGELOG.md](CHANGELOG.md)。

## 数据目录升级

v0.1.16 统一使用 `data/plugin_data/astrbot_plugin_priestess/`。
更新前建议停止机器人并备份旧目录。首次启动会将旧版 `astrbot-plugin-priestess` 目录整体迁移，绑定数据库、抽卡记录、配置和缓存一并保留。
v0.1.17 起，Windows 热更新时如果目录被占用或无重命名权限，本次继续使用旧目录，并在日志提示；不会复制或覆盖正在使用的数据库，重启 AstrBot 后会重新尝试迁移。
如果新旧两个目录均包含数据，插件会停止迁移并报错，避免自动覆盖；请停止机器人、备份并核对目录后再重启。
